# Web App Showcase for VAE+RSVD Recommender

## Context

The thesis project trains a hybrid VAE + RSVD recommender on MovieLens 100K (943 users × 1682 items). The models are serialized as TensorFlow weights and NumPy `.npy` arrays under `Data/SavedModels/`. The user wants a **localhost-only** Netflix-style web app to demo the model: a fake username/password login screen accepts a user_id from the 943-user dataset, then shows that user's ratings and the model's recommendations as horizontal poster carousels grouped by genre.

Decisions from the clarification round:
- Posters: TMDB API with a pre-built local cache
- Layout: "Already Rated" + "Top Recommended" rows **plus** genre shelves (Action, Drama, …) built from the 19 genre flags
- Hosting: localhost only — no Docker, no deployment config
- Login: fake username/password form (username = user_id, password ignored)

## Tech Stack

| Layer | Choice | Why |
|---|---|---|
| Backend | **FastAPI** (Python 3, uvicorn) | Same runtime as `Scripts/model.py` — loads the trained VAE and RSVD arrays directly. Async + `/docs` for free. |
| Frontend | **Next.js + React + Tailwind CSS** | `next/image` for poster optimization; Tailwind's `flex overflow-x-auto snap-x` is one-line for Netflix-style shelves. |
| Carousel | Native CSS scroll-snap, optionally **Embla Carousel** for arrow buttons | Tiny, no Netflix-clone lib needed. |
| Posters | **TMDB API**, fetched once via Python script → `posters_cache.json` | One free API key, no per-request hits to TMDB. |

## Backend design

Single-process FastAPI app. At startup:

1. Read `Data/HyperParameters/tuning_progress_vae.json` to recover VAE architecture (`hidden_dims`, `latent_dim`, `dropout_rate`).
2. Rebuild VAE from `Scripts/model.py`'s `Encoder`/`Decoder`/`VAE`, call once on `train_data[:1]` to materialize variables, then `load_weights('Data/SavedModels/trained_best_vae_weights.weights.h5')`.
3. Load RSVD arrays: `final_mu.npy`, `final_b_u.npy`, `final_b_i.npy`, `best_U.npy`, `best_Sigma.npy`, `best_V.npy`.
4. Read latest `Data/EvaluationResults/final_testing_results_*.json` for `ensemble_weights.best_alpha_vae` (currently ~0.25).
5. Precompute the full predicted matrix once and keep it in RAM:
   ```
   pred_vae  = vae.decoder.predict(vae.encoder.predict(train_data)[0])
   pred_rsvd = mu + b_u[:,None] + b_i[None,:] + U @ Σ @ V.T
   pred_full = clip(alpha*pred_vae + (1-alpha)*pred_rsvd, 0, 1) * 5  # 943×1682, ~6 MB float32
   ```
6. Load `u.item` / `u.user` / `u.data` via pandas (pipe-separated, **1-indexed** — keep IDs 1-indexed everywhere; only convert to 0-index when slicing arrays).
7. Load `posters_cache.json` into a dict.

### Endpoints

| Method | Path | Returns |
|---|---|---|
| `POST` | `/api/login` | `{user_id, age, gender, occupation}` if user_id ∈ [1, 943]; 401 otherwise. Password field accepted but ignored. |
| `GET`  | `/api/users/{id}/rated` | `[{movie_id, title, year, rating, poster_url, genres}]`, sorted by actual rating desc |
| `GET`  | `/api/users/{id}/recommendations?limit=50` | Top-N unrated movies by predicted rating, same shape |
| `GET`  | `/api/users/{id}/recommendations/by-genre?limit=20` | `{action: [...], drama: [...], comedy: [...], ...}` — one row per genre flag, top-N unrated within each |
| `GET`  | `/api/movies/{id}` | Full metadata + poster + overview (for optional detail modal) |

### Files (new) — `Programs/App/backend/`

- `app.py` — FastAPI app, CORS for `localhost:3000`, route handlers
- `inference.py` — model loader, precomputed `pred_full` matrix
- `data.py` — pandas loaders for `u.item`, `u.user`, `u.data`; helpers to map between 1-indexed IDs and 0-indexed array positions; genre column constants
- `fetch_posters.py` — one-shot CLI: read `u.item`, hit TMDB `/search/movie?query=<title>&year=<year>`, write `posters_cache.json` keyed by `item_id` → `{poster_url, tmdb_id, overview}`. Sleep 0.25 s between calls; resume on rerun.
- `posters_cache.json` — output of the script (committed once built so the backend has no live external dep)
- `.env` — `TMDB_API_KEY=…` (gitignored)

Paths from `backend/` to data: `../../Data/...` and `../../Scripts/model.py` (two levels up from `Programs/App/backend/` to `Programs/`).

## Frontend design

Next.js App Router project at `Programs/App/frontend/`. Pages:

- `app/login/page.tsx` — centered username/password form on a dark background, Netflix-red submit button. POSTs to `/api/login`, stores user_id in `localStorage`, redirects to `/`.
- `app/page.tsx` — main browse view. On mount, reads user_id from `localStorage` (redirect to `/login` if missing), then fetches in parallel:
  - `/api/users/{id}/rated` → "Already Rated" shelf
  - `/api/users/{id}/recommendations?limit=50` → "Top Recommended" shelf
  - `/api/users/{id}/recommendations/by-genre?limit=20` → one shelf per genre

### Components (`app/components/`)

- `Shelf.tsx` — title + horizontal scrollable row of `MovieCard`s (CSS scroll-snap, optional Embla arrows).
- `MovieCard.tsx` — `next/image` poster (w-40 aspect-[2/3] rounded-md), hover lifts + shows title/year/rating overlay. Skeleton fallback if poster missing.
- `Navbar.tsx` — Netflix-style top bar with logo, current "user name", logout (clears localStorage).

Tailwind config: dark mode default, accent `#E50914` (Netflix red).

## Verification

1. **Poster cache**: run `python App/backend/fetch_posters.py`; spot-check 3–5 entries in `posters_cache.json` against TMDB.com (e.g. movie 1 = "Toy Story (1995)").
2. **Backend smoke**: `uvicorn App.backend.app:app --reload` (run from `Programs/`), open `http://localhost:8000/docs`, hit `GET /api/users/1/rated` — should return ~270 movies (user 1 is the heaviest rater).
3. **Parity check**: compare `GET /api/users/1/recommendations?limit=10` against `pred_hybrid_clipped` computed in `Notebooks/Testing.ipynb` for the same user_id → top items and predicted scores must match within floating-point noise.
4. **Login**: `POST /api/login {username: "1", password: "anything"}` → 200; `{username: "9999"}` → 401.
5. **Frontend**: `npm run dev` (port 3000), log in as user 42, confirm:
   - Already-rated row shows movies, sorted by rating desc
   - Top-recommended row excludes movies in already-rated row
   - Each genre shelf shows only movies tagged with that genre
   - Horizontal scroll snaps; posters lazy-load

## Implementation order

1. `fetch_posters.py` + run it (slowest external step, do first so frontend has data to show).
2. `inference.py` — load models, build `pred_full`. Test in a one-off script that prints top-5 for user 1.
3. `data.py` + `app.py` — endpoints. Verify each in `/docs`.
4. `frontend/` scaffold (Next.js + Tailwind), login page, fetch + render shelves.
5. Genre shelves + styling polish.
